# ISL xG Tracker 2026-27

The public, read-only page of an independent project that tracks shot-by-shot expected goals (xG) in the Indian Super League 2026-27 season: match timelines, plus xG, xA and goalkeeper numbers for every player and club.

**Live page:** https://aadityanarayan28.github.io/isl-xg-tracker/

## How this repository works

`index.html` is the whole site. It is saved from the private tracker with its "Save public page" button and holds every finished match. To update the site, replace `index.html` on the `gh-pages` branch with a freshly saved copy.

## Credit
